
### Custom commands.
- These are some of the most helpful tools I have in managing git workflows.

Add these scripts to your .bashrc file via:

```
sudo nano ~/.bashrc
```

I've got **gnew** for creating new projects (and **gnew-p** for doing the same thing with private projects)

I've got **gconnect** for syncing with existing repos

And, **gtag** helps an AI agent understand more about your project by providing logs, project directories, versioning, notes and more all handled automatically by your useage of git.
